# 国际版参考与设置测试页

2026-10-04 将默认示例替换为由公共组件组成的设置测试页。连续设置行、浅灰顶栏和灰色目录参考国际版 Bedrock 的设置与存档编辑画面，旧图鉴保留为 `LegacyOrePlayground`。

## 本轮修改

- 公共 `OreNavigationItem` 分别处理灰色选中与 hover，`OreListItem` 的白框列表语义独立保留。
- `OreDivider`、`OreSettingsRow`、`OreSettingsSection` 统一双线分隔、标题、说明和行间距。
- `OreSegmentedControl` 支持普通选项和带图标权限选项，选中短线居中。`OreTabs` 支持带图标页签。
- 开关使用国际版实测的 30×16 方形手柄与轨道，default 和 hover 分开采样。
- 输入框补齐上方内凹边，空值提示位于框内。静止文字用提前烘焙字体，编辑状态保留原生输入法和光标。
- 下拉菜单使用统一灰色选项、细分隔、居中标题和透明关闭图标。长菜单独立滚动。
- 整数滑块拖动期间保留原生连续位置，业务接收整数，松手时吸附到对应档位。被控值、拒绝更新和卸载清理有契约覆盖。
- 分段刻度保留原生工厂的 `$step_offset`，使用 1×6 竖线；进度纹理不使用导致填充超出手柄的九宫格裁剪。
- 字体使用源 ZIP 的 Noto Sans SC Regular 和 Minecraft Seven，30759 个字形、50 页图集。以前的 Medium 字体记录已过期。
- 资源图鉴保留 589 项的搜索、分页、等比完整预览和动画暂停。GIF 使用源逐帧时长。
- 窄屏目录改成可收起抽屉，页面选择后关闭。关闭按钮与分页使用图标。
- 测试页展示 raised、flat、禁用按钮，开关与复选框的开关及禁用状态、受控与非受控模式，以及世界卡片、帮助、消息和三种弹窗。
- 实际像素差分发现输入框 JSON 九宫格顺序错误，导致上方内凹边拉长；现在使用左、上、右、下的 `[1, 3, 1, 1]`。SDK 九宫格接口仍采用左、右、上、下。
- 分段选项固定底部反光边和按下边，相邻边框共享 1 个逻辑像素。权限图标新增保留原 alpha 的白色蒙版，使原本黑色的源资源可以正确着色，选中为白色，未选中为深色。
- 侧栏选中项的上边为暗边、下边为亮边，未选中 hover 的明暗顺序相反，按国际版采集分别处理。

## 证据与限制

最终结果由 `tools/verify_settings.py`、`verify_settings_viewports.py` 和 `verify_settings_pixels.py` 产生。运行方法见 [VALIDATION.md](VALIDATION.md)。旧图鉴通过次数不属于当前设置页。

国际版参考来自 `1.26.5203.0`，包括可访问性、视频、游戏列表和存档通用、高级、多人游戏。最新 default 和 hover 用绝对桌面输入重新采集。来源与状态详见 [international-evidence.json](international-evidence.json)。

生成皮肤审查中，滑块手柄 default 与 hover 在显式 4 倍展开后的通道误差为零；开关 on 有两个像素出现 1 通道值差异。off 开关截图位于非整数垂直位置，边缘存在混合误差，不能将整张 crop 记为零差异。实际游戏渲染是独立检查，不能从皮肤比较推导整页 1:1。

解锁后完整触屏回归通过 68 项，三种尺寸适配通过 172 项。切片和图标修正后，定点鼠标与触屏回归通过 18 项，宿主检查通过 7 项，Python 2.7 契约通过 26 项。详情与批次范围见 [VALIDATION.md](VALIDATION.md)。

实际渲染的 16 处裁切比较已保存，均使用与参考相同的物理控件尺度。九处原像素一致：分段选项侧边四种状态、输入框左边两种状态、滑块手柄两种状态和未选中侧栏的默认侧边。开启开关两种状态仅两个像素出现单通道差值 1。侧栏选中与 hover 的边缘仍有约 5.21% 的像素不同，平均通道误差为 0.50 到 0.72；关闭开关有约 8.91% 的像素不同，平均误差为 1.15 到 1.21。数值按 0 到 255 的 RGB 通道计算，没有排除差异像素。

当前国际版的 GUI 缩放已使用分段按钮；用户提供的旧版下拉弹层仍作为该组件的参考。弹窗、世界卡片、字体栅格、键盘焦点和全部 pressed 尚未达到逐像素一致。Windows F11 验证仅代表单指触屏模拟，真实手机、软键盘和多指没有硬件测试结果。
