# 国际版参考与设置测试页

2026-10-04 的示例使用公共组件组成存档设置界面，包含 13 个分区和好友抽屉。世界预览、资源包列表、玩家分组和操作菜单分别封装，示例只提供业务状态与回调。

## 本轮修正

- 相接选项保留共用边框，选中项下沉，文字位置与未选中项分开处理。页签的选中底线和明暗边按完整参考修正。
- 设置行使用两色分隔线，侧栏分组保留标题与空白。设置顶栏标题独立居中，社交入口不会推偏标题。
- 滚动条采用 Ore 轨道与手柄，覆盖完整宽度的视口，设置内缩位置与长度。嵌套滚动内容不撑大外层范围。
- 连续与整数滑块的手柄中心沿内缩 8 单位的范围移动。刻度、文字与手柄使用相同有效范围，最左端进度补上封口。手柄层级写在 native 模板中，避免每次布局调用 SetLayer 破坏拖动。
- 禁用滑块保留暗色进度，刻度为灰色，手柄明暗边按国际版采样修正。业务值与禁用输入分别检查。
- 输入框保留内凹上边。烘焙文字的裁剪区域修正了首字笔画被切掉的问题，原生编辑框的位置与宽度保留。
- 西文字体改用源包 Minecraft Seven v2，数字 advance 与参考相符。正文加入源 CSS 的字间距，布局、居中、换行与绘制共享同一度量。
- 单选改为源 CSS 的菱形指示器。整行可点按，default、hover、pressed、selected 和 disabled 分别绘制。
- 资源包预览与激活按钮独立命中。可用与活跃页签、资源包分组数量、详情展开、激活与停用均可交互。分组标题和计数下移半个逻辑像素后，完整控件平均通道误差由 2.09 降至 1.42，hover 时由 1.82 降至 1.23，仍未达到零差异。
- 好友抽屉包含搜索、好友与队伍页签、当前玩家、在线空状态、离线玩家、独立选项按钮和操作菜单。补充图标保存截图版本、原图哈希和提取方式。
- 玩家操作菜单采用固定标题、独立首项和后续选项分组。按物理像素修正行高、文字缩进、关闭图标和在线标记，正文较长时单独滚动。
- 好友抽屉上打开操作菜单时，菜单使用更高的模态层级。组合界面额外检查关闭按钮，避免抽屉挡住菜单右侧。
- 好友搜索与编辑弹窗使用不与原生输入框重叠的透明命中区域。表面采用普通容器，避免按钮祖先截获焦点。两种输入模式检查真实文字、列表过滤与关闭后事件清理。
- 玩家行默认头像不含在线状态，离线示例不再误显示绿色在线标记。
- 资源图鉴完整显示等比预览，支持搜索、分页和动画暂停。GIF 保留源逐帧时间。

## 完整像素验收

国际版为 `1.26.5203.0`，网易开发客户端为 `3.9.0.401155`。最新 26 状态结果见 [validation-latest.json](validation-latest.json)，复现命令见 [VALIDATION.md](VALIDATION.md)。

比较使用 actual game rendering，保留全部文字、图标、控件边框和外围 1 个逻辑像素。参考与实现均为每逻辑像素 4 个物理像素。半开裁切区间分别舍入两端，不通过改尺寸、搜索偏移或文字蒙版降低验收误差。

**最新 26 个状态中，0 个达到完整控件原像素一致，不能声称 1:1 完成。** 文字度量修正显著减少了长名字与菜单标题的宽度差异，分隔位置修正消除了小数行高累积偏差，但字体边缘采样、分数坐标、局部边框及周围背景仍存在误差。每个状态分别记录平均通道误差、最大误差、不同像素比例与差异范围。平均误差以 0 到 255 的 RGB 通道计算，零容差结果保持失败。

## 交互与窗口

完整鼠标、F11 单指触屏回归检查了 226 项。菱形单选另有 20 项原生命中、hover、指示器几何、父容器边界、禁用及输入模式恢复检查。最终字段与菜单布局修改后的复查范围单独记录在最新 JSON 中，避免将修改前的批次描述成全部最终源码的验收。

三种客户区逐页检查 13 页的边界与图像几何，包含窄屏目录、三种弹窗、好友抽屉与操作菜单。整数滑块逐档检查回调整数、原生整数、手柄中心和端点越界。游戏业务回调与实际像素是两套独立证据。

完整适配通过 203 项。最终输入与单选修正后，开关、输入框和好友页在同样三种尺寸下补充通过 66 项，包含单选组位于分隔线之前的检查。报告将这两次批次分开保留。

好友菜单遮挡修正后，同样三种尺寸补充通过 40 项，其中实际点按操作菜单右上角关闭按钮，确认它位于好友抽屉之上。本批次使用 F11 单指模拟，窗口边界及业务回调分别保存。

模态输入及背景拦截修复后新增 32 项鼠标与 F11 触屏检查，覆盖真实好友搜索、过滤列表、菜单关闭及最后一项回调、编辑弹窗、有效命中区域、背景关闭不触发底层导航和命中拦截器注销。最终源码的鼠标功能补测通过 40 项，覆盖下拉、资源包、三种弹窗、背景拦截、好友操作和资源图鉴。短下拉菜单底部补足 1 个逻辑像素，三项列表不再显示多余滚动条。该修正后另有 14 项鼠标与 F11 检查，包含截图后的再次点击、短菜单完整内容范围、实际选项选择、长菜单关闭、背景关闭与底层导航拦截。早先只验证布局和回调的批次不能作为真实搜索输入通过的证据。

最终模态布局在 1200×540、1008×1440 与 540×800 三种客户区补测通过 78 项，覆盖下拉、三种弹窗、窄屏目录、好友面板与操作菜单。短菜单高度最后调整后，下拉页在同样三种尺寸补测通过 22 项。每次测试后恢复窗口与鼠标模式。

当前仍缺少 Android、iOS、软键盘、多指、手柄焦点和全部 pressed 状态验收。同版本单选 native 参考尚未采集，形状依据源 CSS 与 Wiki。部分旧下拉菜单在当前国际版已改为分段选项，因此用户图片与源 CSS 支撑旧菜单形状，不能声称与本机同版本的同款菜单原像素一致。
